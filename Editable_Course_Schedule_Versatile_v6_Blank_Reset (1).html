Editable Course Schedule

Click the page title, week numbers, dates, column headers, or cards to edit them. Add/remove columns and date rows as needed, or auto-fill dates from a term start/end date and meeting days, or import an existing Excel schedule saved as CSV. Drag cards to move them. Print/Save PDF uses compact print styling.

Column editing: click a column header to rename it. Use + Add column to add a new category column. New columns can either repeat for each class date or span the whole week, like Recitation. Removing a column moves its cards into the first remaining column so you do not lose content.
Row editing: use + row inside a week to add another class meeting row. Use + Add row to every week if a course meets three times per week. Removing a date row moves its cards to another row in the same week. Use Auto-fill dates to rebuild the week/date rows from a start date, end date, and selected class meeting days. Use Import CSV / Excel paste to bring in an existing schedule from Excel; save the Excel sheet as CSV or copy/paste the table range.

Auto-fill dates

This updates the Week and Dates rows automatically. Holidays, breaks, and unusual class days can still be edited, added, or removed manually after generation.

Import from Excel / CSV

In Excel, save the schedule sheet as CSV UTF-8, or copy the table range from Excel and paste it below. The first row should contain headers such as Week, Dates, Topic, Homework, Quizzes, Project, Bonus, and Recitation.

Importing replaces the current schedule, so use Download backup first if you want to save your existing work. Native .xlsx files should be saved as CSV first.

Your edits are stored in this browser's local storage. To keep a portable copy of changes, use Download backup.
